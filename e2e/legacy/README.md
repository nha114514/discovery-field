# Superseded adaptive-learning browser tests

These scripts preserve coverage of the previous intake, diagnosis, quiz,
mastery, density, and fixed Transformer-map workflow. On 2026-10-01 the public
product changed to open-topic reading without learner-facing assessments.

They are retained as historical source, not current Playwright specifications.
The active suite is `../open-knowledge.spec.ts`. Unit tests for the retained
domain modules remain in `tests/` and still run through `npm test`.
