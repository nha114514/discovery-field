## Before publishing source

- [ ] Confirm `.env.local` is ignored and absent from the repository upload.
- [ ] Exclude credentials, local logs, browser profiles, `node_modules`, `.next`,
      and temporary files. Include `.env.example` and `package-lock.json`.
- [ ] Review all selected files before pushing; much of this local workspace is
      currently untracked. Do not use a blind `git add .` as the review step.
- [ ] Keep the AI disclosure in the root README.
- [ ] Check the public repository in a signed-out browser and test its setup guide.
- [ ] Do not advertise earlier grading, locked routes, or mastery features as
      active in the submitted product.

## Before final submission

- [ ] Ensure screenshots, video, written claims, and repository all show the
      same version.
- [ ] Read `EDITORIAL-REVIEW.md`; approve or replace the captured AI-generated
      example before treating the video draft as final.
- [ ] Watch the final uploaded video and verify audible English narration or
      English subtitles; confirm duration is within 2–5 minutes.
- [ ] Verify all public links are readable without your personal login.
- [ ] Recheck all mandatory Devpost fields and save before the deadline.
- [ ] Submit personally after checking eligibility and the final form.

This package prepares materials only. It does not create a public repository,
upload the video, publish an API-backed app, or press Submit.
