# Discovery Field — submission pack

Prepared on 1 October 2026 for **GIBC V2 · Track 03: Open Track**.

This package describes the current open-topic reader, not the retired quiz and
learner-grading workflow. This repository contains the source and screenshot
materials. The competition entry remains a draft, not a finalized submission.

are deliberately not included in the public source repository. The current
video draft needs the editorial corrections described above before publication.

## Official requirements checked today

The [official rules](https://gibc-v2.devpost.com/rules) require an English project
description, a public source repository, a 2–5 minute running-project video,
the Built With list, team information, and at least three images. AI development
tools must be disclosed in Built With and the README. The deadline is
**1 October 2026, 23:45 Taipei time (UTC+8, also Beijing time)**.

The public repository URL, public video URL, and the entrant's real name and
Devpost account must be provided by the entrant. Check eligibility and original
development dates yourself; this pack does not assert those personal facts.

Do not upload `.env.local`, API keys, browser profiles, or private logs. Before
publishing a live deployment, rotate any key previously pasted into a chat and
add provider spending limits. The prototype currently lacks abuse controls.
